# 트윗용 콜라주 메이커

사진 여러 장을 트위터(X)에 올리기 좋은 콜라주 이미지나 GIF로 만들어 주는 웹 도구예요.
서버 없이 브라우저에서만 동작하고, 사진은 내 기기 밖으로 나가지 않아요.

## 기능

- 비율: 16:9, 1:1, 4:5, 3:1(프로필 헤더)
- 배치: 그리드, 하나 크게, 가로 한 줄, 세로 한 줄
- 사진별 위치(드래그)와 확대(휠·슬라이더) 조절, 순서 변경
- 간격, 모서리 둥글기, 바깥 여백, 배경색
- 아래 캡션(제목, 크레딧)
- JPG / PNG 저장
- GIF 저장 (한 장씩 넘기기, 차례로 채우기)

## 사용

`index.html`을 브라우저로 열면 바로 쓸 수 있어요. 빌드 과정은 없어요.

## GitHub Pages로 배포

1. 이 저장소에 `index.html`과 `README.md`를 올려요.
2. 저장소의 **Settings → Pages**로 가요.
3. **Source**를 `Deploy from a branch`로 두고, 브랜치는 `main`, 폴더는 `/ (root)`로 골라 저장해요.
4. 1~2분 뒤 `https://<내 아이디>.github.io/<저장소 이름>/` 주소로 열려요.

## 참고

- 폰트(IBM Plex Sans KR)는 Google Fonts에서 불러와요. 오프라인에서는 기본 폰트로 대체돼요.
- GIF 인코더는 외부 라이브러리 없이 `index.html` 안에 직접 들어 있어요.
- 모바일에서 자동 다운로드가 막히면, 저장 후 아래에 나오는 이미지를 길게 눌러 저장하면 돼요.
